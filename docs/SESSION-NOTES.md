## Gotchas learned

- **Quick Settings → Theme tiles** apply a *Global Theme*. WhiteSur's Liquid global themes referenced names that don't exist (`WhiteSurLiquidDark`, `WhiteSurLiquidDark-cursors`, …), so selecting a tile reset everything to Breeze. Fixed versions are in `configs/look-and-feel/*/defaults`, and `DefaultDarkLookAndFeel` now points to `WhiteSurLiquid-dark`. Avoid the "Breeze Twilight" and "Automatic" tiles.
- **Restarting plasmashell** resets the top panel's height to 36. Set it back to 24 afterwards, which `install.sh panels` does.
- **Plasma scripting:** a panel's `hiding` value doesn't read back reliably. The value saved on disk is `panelVisibility=3` in `plasmashellrc`.
- **Theme edits need a cache refresh:** after editing a theme SVG, delete `~/.cache/plasma_theme_WhiteSurLiquid*`, then switch the Plasma style away and back (`plasma-apply-desktoptheme WhiteSur-dark && … WhiteSurLiquid-dark`).
- **Terminal looks opaque?** Alacritty keeps `opacity = 0.8`; if it looks solid, check the wallpaper. The desktop once switched to a plain black colour wallpaper (`wallpaperplugin=org.kde.color`). Current wallpaper: macOS 27 "Golden Gate Dark" from 512pixels.net, saved in `~/.local/share/wallpapers/macos/Golden-Gate-Dark.png` and applied with `plasma-apply-wallpaperimage <file>`.
- **Screenshots work** with `spectacle -b -n -f -o <file>` and can be read back to check changes visually.
- **`fish_add_path` returns 1 when the path is already there**, which stops `install.sh` (it runs with `set -e`); the call is guarded with `|| true`.
- **New AppImages (static runtime) run without FUSE 2**: they use `fusermount3`. Only older ones need `--appimage-extract`.
- **The scratchpad (`/tmp/claude-…`) can disappear** between turns, so keep anything important in this folder.

## Crisp dock edges, no artifacts

- **Edge layers in whole screen pixels:** each layer is exactly one device pixel wide (`PX = 1/DEVICE_SCALE`, so ⅔ of a layout pixel at 150%): a 30% dark outline, the bright highlight and a faint inner sheen. Straight edges land on the pixel grid and are razor sharp. Feathered layers looked soft and were dropped. **If the display scale changes, update `DEVICE_SCALE` in the generator.**
- **Blur artifact:** stair-steps one layout pixel wide appeared outside the rounded corners. They come from KWin's blur area for the panel, which Plasma computes at layout resolution from the panel shape. It ignores the theme's `mask-*` elements: a test with `MASK_INSET = 6` didn't change the steps.
- **Fix:** panel blur is turned off with `[BlurBehindEffect] enabled=false` in the theme's `plasmarc` (original kept as `plasmarc.orig`). The trade-off is that the dock is truly see-through, not frosted, and Plasma pop-ups lose their blur too. To bring it back, delete that group and reapply the Plasma style.

## Dock corner shape

- The user found the circular 20px corners too round on the 44px dock, after asking to compare with the real macOS dock. No published dock measurements were found, so the shape follows Apple's general continuous-corner style.
- Corners are now Apple-style *continuous* corners: a superellipse with exponent `N = 5` over a 22px corner area (`R = 22`, raised from 18 in two steps at the user's request; 22 is the maximum for the 44px dock). That's roughly a 14px visual radius, with a gentle start where the curve meets the straight edges.
- `R * DEVICE_SCALE` must stay a whole number (22 × 1.5 = 33) so corner tiles stay on the pixel grid.
- To make the corners rounder or squarer, change `R` (size) or `N` (2 = circle, higher = squarer).
