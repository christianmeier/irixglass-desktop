# Changelog

Notable changes per release. The release notes on GitHub add the full commit list since the
previous tag. Versions follow [semver](https://semver.org); `VERSION` holds the current one.

## [0.1.0]

First release.

- **fm**: the IRIX Indigo Magic–style file manager with the macOS Tahoe glass look (notebook tabs,
  split view, Finder tags and columns, Quick Look, terminal, Neovim and web tabs, KIO network folders).
- **IrixGlass**: fm's look for the rest of the desktop: Aurorae title bars, Kvantum, GTK 3/4,
  Plasma pop-ups, colour scheme, Firefox and Teams CSS.
- **Desktop**: macOS-style menu bar and floating dock, Spotlight-style KRunner, KWin window menu,
  and `scripts/install.sh` to set it all up.
